# 数据目录说明

本目录用于存放项目所需的数据文件。

## 目录结构

```
data/
├── raw/              # 原始数据
│   ├── videos/       # 无水印视频文件（.mp4格式）
│   └── watermarks/   # 水印图像文件（.png、.jpg、.jpeg格式）
├── processed/        # 处理后的数据
└── synthetic/        # 合成的数据
```

## 数据准备指南

### 1. 无水印视频

请将您的无水印视频文件放入 `raw/videos/` 目录中。

**要求：**
- 格式：MP4（推荐），也支持其他常见格式
- 数量：建议至少100个视频片段
- 时长：每个视频片段建议10-60秒
- 分辨率：建议720p或更高（模型会自动调整到256x256）

### 2. 水印图像

请将您的水印图像文件放入 `raw/watermarks/` 目录中。

**要求：**
- 格式：PNG（推荐，支持透明通道）、JPG、JPEG
- 数量：建议至少20种不同类型的水印
- 类型：文本水印、Logo水印、半透明水印等
- 尺寸：建议100x100到500x500像素之间

## 数据增强

模型训练时会自动进行以下数据增强：
- 随机裁剪
- 水平翻转
- 随机旋转（±10度）
- 亮度调整（0.8-1.2倍）
- 对比度调整（0.8-1.2倍）

## 合成数据集

训练时会自动在无水印视频上添加随机水印，生成合成训练数据。水印会随机变化：
- 水印类型：从watermarks目录中随机选择
- 水印大小：50-150像素
- 水印位置：随机放置在帧的任意位置
- 水印透明度：0.1-0.5

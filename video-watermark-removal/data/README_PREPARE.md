# 数据准备指南

本指南详细说明如何为视频水印去除模型准备训练数据。

## 目录结构

```
data/
├── raw/              # 原始数据
│   ├── videos/       # 无水印视频文件（.mp4格式）
│   └── watermarks/   # 水印图像文件（.png、.jpg、.jpeg格式）
├── processed/        # 处理后的数据
└── synthetic/        # 合成的数据
```

## 数据准备步骤

### 1. 收集无水印视频

**方法1：使用DownKyi工具**
- 下载地址：https://gitcode.com/gh_mirrors/do/downkyi
- 功能：专门用于B站视频下载，可提取无水印视频流
- 使用方法：
  1. 安装并运行DownKyi
  2. 复制B站视频链接
  3. 在工具中粘贴链接
  4. 选择"原始流"选项下载

**方法2：使用在线解析服务**
- 推荐网站：bilibili-video-download.com
- 使用方法：
  1. 粘贴B站视频链接
  2. 选择"原画"或"高清源"版本
  3. 下载无水印视频

### 2. 收集水印模板

**方法1：从B站视频中提取**
1. 播放B站视频
2. 截图包含水印的区域
3. 使用图片编辑工具裁剪出水印
4. 保存为透明PNG格式

**方法2：创建自定义水印**
1. 使用Photoshop或GIMP创建水印
2. 包含文字（如"bilibili"）和简单图形
3. 保存为透明PNG格式

### 3. 数据要求

**视频要求：**
- 格式：MP4
- 数量：至少100个视频片段
- 时长：每个视频10-60秒
- 分辨率：720P或更高
- 类型：覆盖不同场景（科技、生活、游戏、动漫等）

**水印要求：**
- 格式：PNG（推荐，支持透明通道）
- 数量：至少20种不同样式
- 大小：100x100到500x500像素
- 类型：文字水印、Logo水印、半透明水印等

### 4. 数据增强

模型训练时会自动进行以下数据增强：
- 随机裁剪
- 水平翻转
- 随机旋转（±10度）
- 亮度调整（0.8-1.2倍）
- 对比度调整（0.8-1.2倍）

### 5. 合成数据集

训练时会自动在无水印视频上添加随机水印，生成合成训练数据。水印会随机变化：
- 水印类型：从watermarks目录中随机选择
- 水印大小：50-150像素
- 水印位置：随机放置在帧的任意位置
- 水印透明度：0.1-0.5

## 快速开始

1. 在 `data/raw/videos` 目录中放入无水印视频
2. 在 `data/raw/watermarks` 目录中放入水印图像
3. 运行训练脚本：
   ```bash
   python training/train.py --video_dir data/raw/videos --watermark_dir data/raw/watermarks
   ```

由于环境限制，我们无法直接生成示例数据。请按照上述步骤准备真实的训练数据。

## 注意事项

1. 确保所有视频和水印文件命名安全，不包含特殊字符
2. 视频文件大小建议控制在100MB以内，便于处理
3. 水印文件建议使用透明背景，效果更佳
4. 数据多样性是模型性能的关键，尽量收集不同类型的视频和水印
